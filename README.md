# OTP Manager

ワンタイムパスワードを管理できる軽量でシンプルなデスクトップアプリです。

タスクトレイに常駐し、登録したアカウントの6桁コードを一覧で表示します。Windows 用。

## ダウンロード

[Releases](https://github.com/ShiroganeKotora/OTPManager/releases) から `OtpManagerSetup.exe` をダウンロードして実行してください。

管理者権限は不要です。インストール先はユーザーごとの領域で、変更はすべてこのユーザーの範囲に留まります。インストーラが作成するのは次の4つで、実行前に確認画面で提示されます。

- デスクトップとスタートメニューのショートカット
- **ユーザー環境変数 `PATH` へのインストール先の追加**（コマンドラインから起動できるようにするため。システム側の `PATH` は変更しません）
- 「アプリと機能」への登録
- 設定の保存先フォルダ

アンインストールは「アプリと機能」からでも、同梱の `uninstall.exe` からでも行えます。`PATH` の登録も同時に取り除かれます。

既にインストールされている場合、同じインストーラが更新・修復として動作します。登録済みのアカウントと設定はそのまま残ります。

## できること

- **時刻同期ワンタイムパスワード（TOTP）の生成** — RFC 6238 準拠。SHA1 / SHA256 / SHA512、6〜10桁、周期10〜300秒
- **QRコードの読み取り** — 画像ファイル、クリップボード、データURI から登録
- **QRコードの表示** — 登録内容をQRで表示し、他の端末へ移せます
- **グループ分け** — 見出しを付けて整理。ドラッグで並べ替え、折りたたみも可能
- **ライト / ダークテーマ** — Windows の設定に追従、または個別に指定
- **バックアップ** — パスフレーズで暗号化した書き出しと読み込み
- **時刻のずれの補正** — 端末の時計がずれていてもコードが合うように調整（[通信について](#通信について)）

## 使い方

| 操作 | 動作 |
|---|---|
| 行を左クリック | コードをクリップボードへコピー |
| 行をダブルクリック | 編集 |
| 行を右クリック | コピー / 編集 / 削除 / 並べ替え |
| 行を上下にドラッグ | 並べ替え |
| 行の右上のアイコン | QRコードをウィンドウ内に表示 |
| そのアイコンを右クリック | 画像を保存 / base64形式でコピー / URI形式でコピー |
| ウィンドウを閉じる、Esc | トレイへ格納（終了しません） |
| Ctrl+F | 絞り込み |
| トレイアイコンをクリック | ウィンドウ表示 |
| トレイを右クリック → 終了 | 終了 |

### アカウントの登録

ツールバーの追加ボタンから、シークレット欄に `otpauth://` 形式のURIを貼り付けると、発行者・アカウント名・桁数・周期・アルゴリズムがすべて自動で入ります。QRコードの中身がこの形式です。

Base32のシークレット文字列を直接貼っても構いません。空白・ハイフン・`=` は無視されます。

### QRコードの読み取り

ツールバーの読み込みボタンから、画像ファイルまたはクリップボードのQRコードを読み取れます。クリップボードにテキストが入っている場合はそれを直接解釈するので、画面を切り取った画像でも、コピーしたURI文字列でも構いません。`data:image/png;base64,...` のようなデータURIにも対応しています。

対応する形式は2つです。

- `otpauth://totp/...` — 1件を追加します
- `otpauth-migration://offline?data=...` — 複数件をまとめて取り込みます

後者が複数枚に分かれている場合は、全何枚中の何枚目かを表示します。登録済みのものは自動で除外され、カウンタ同期（HOTP）は非対応のため取り込みません。

### グループ

グループを作ると、見出しの下にアカウントをまとめられます。未分類のアカウントは見出しなしで並び、グループとグループの間にも置けます。

見出しをクリックすると折りたたみ、ドラッグするとグループごと移動します。グループを削除しても中のアカウントは消えず、未分類に戻るだけです。

絞り込み中は折りたたみを無視して、一致する行を表示します。

## 保存場所

```
%APPDATA%\OtpManager\accounts.json
```

シークレットは **Windows DPAPI（CurrentUser スコープ）で暗号化**して保存されます。このファイルを他のPCや他のユーザーアカウントへコピーしても復号できません。

**裏を返すと、Windows のユーザープロファイルが失われるとシークレットも失われます。** 各サービスの復旧コードは必ず別途保管してください。

## 通信について

このアプリが外部へ接続するのは、環境設定の「時刻の同期」で **「ずれを確認」を押したときだけ** です。

    https://www.cloudflare.com/cdn-cgi/trace

に対して認証なしのGETを1回送り、応答が返す時刻と端末の時計を比べます。登録内容や端末の情報は一切送りません。それ以外の場面で通信は発生せず、更新確認も自動送信も行いません。

## バックアップ

保存ファイルは上記の理由で他のPCへ持ち出せません。環境設定の「バックアップ」から、**パスフレーズで暗号化した書き出し**を作れます。こちらは別のPCでも読み込めます。

AES-256-GCM で暗号化し、鍵は PBKDF2-SHA256（210,000回）で導出しています。**パスフレーズを忘れると復元できません。**

## ビルド

.NET 10 SDK が必要です。アプリ本体だけをビルドする場合:

```
dotnet build -c Release src/OtpManager.csproj
```

インストーラまで作る場合:

```
python tools/build_release.py
```

インストーラとアンインストーラはネイティブAOTでコンパイルするため、MSVC のリンカが必要です。`vswhere.exe` が見つからないと止まるので、その場合は Visual Studio Installer のフォルダを PATH に加えるか、Developer PowerShell から実行してください。
